# Catalog — what each installed skill promises

This file ships as an example. Replace it with your own shelf.
`node scripts/shelf.mjs list` prints what you actually have.

Grouped by domain. Names are exact — pass them to the Skill tool as written.

This file says what a skill **promises**. What it **delivered** when tested lives in `PROFILES.md`,
and that is what breaks a tie when two cover the same ground.

---

## 1. Visual direction

| skill | does |
|---|---|
| `frontend-design` | aesthetic direction for new UI: typography, color, choices that don't read as templated |
| `ui-ux-designer` | wireframes, design systems, user research, accessibility |

## 2. Refining an existing interface

Pick by symptom. All of these operate on something that already exists.

| skill | symptom it treats |
|---|---|
| `polish` | final pass before shipping: alignment, spacing, consistency |
| `critique` | UX assessment: hierarchy, information architecture |
| `audit` | severity report: a11y, performance, theming, responsive |
| `optimize` | slow: load, render, animation, images, bundle |
| `animate` | no feedback, no motion: purposeful micro-interactions |
| `clarify` | confusing copy, labels, error messages |
