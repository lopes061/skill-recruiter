# Probe: list screen on a phone (visual track)

Build a list screen as a single file at `side-N/index.html`. Target width: 390px.

Screen: **cars in a rental fleet**, 12 items. Each car has a plate, a model, a branch,
a status (available / rented / in service / sold) and days idle.

Required:
- one card per car, not a table
- status readable without relying on color alone
- the contact phone number dials on tap (`tel:`)
- a filter or search that acts on click, no framework
- an empty state for when the filter matches nothing
- light and dark themes
- CSS and JS inline. Fonts from Google Fonts only.

Invent plausible plates and models. No real data.

Color, typography, density and hierarchy: the skill decides.
